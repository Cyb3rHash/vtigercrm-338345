# Webmails module (`modules/Webmails/`)

The **Webmails** module provides webmail UI/integration inside vtiger.

## Where to start
- Entity/model: `Webmails.php` (extends `data/CRMEntity.php`)
- Common UI actions:
  - `ListView.php`, `DetailView.php`, `Save.php`
  - AJAX entrypoints (`*Ajax*.php`)
- Assets: `images/`, `js/`

## Related
- `modules/Emails/`
- User mail settings: `modules/Users/`
