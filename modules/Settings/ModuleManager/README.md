# `modules/Settings/ModuleManager/` — module management UI (admin)

This folder contains admin UI/actions for installing, enabling/disabling, and managing vtiger modules.

Typical responsibilities:
- Importing module ZIPs (often from `packages/`)
- Managing module availability and metadata
- Running vtlib-based module lifecycle actions
