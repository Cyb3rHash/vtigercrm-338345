# Potentials module (`modules/Potentials/`)

The **Potentials** module represents sales opportunities.

## Where to start
- Entity/model: `Potentials.php` (extends `data/CRMEntity.php`)
- Common UI actions:
  - `ListView.php`, `DetailView.php`, `EditView.php`, `Save.php`
  - AJAX entrypoints (`*Ajax*.php`)

Related:
- `modules/Accounts/`, `modules/Contacts/`
- Sales documents: `modules/Quotes/`, `modules/SalesOrder/`, `modules/Invoice/`
