# Emails module (`modules/Emails/`)

The **Emails** module supports email composition, storage, and sending workflows in vtiger.

## Where to start
- Entity/model: `Emails.php` (extends `data/CRMEntity.php`)
- Common UI actions:
  - `ListView.php`, `DetailView.php`, `EditView.php`, `Save.php`
- Email templates: `templates/`
- Language files: `language/`

Related:
- `modules/Webmails/`
- Settings mail scanner: `modules/Settings/MailScanner/`
