# Utilities module (`modules/Utilities/`)

This module provides small utility tools in the vtiger UI (calculator, clock, merge tools, etc.).

Key files in this repo:
- `Calculator.php`, `Clock.php`, `Currencies.php`, `Merge.php`
- AJAX: `UtilitiesAjax.php`

Notes:
- Utility/UI-oriented module (not a typical CRMEntity business module).
