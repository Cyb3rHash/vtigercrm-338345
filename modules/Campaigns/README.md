# Campaigns module (`modules/Campaigns/`)

The **Campaigns** module supports marketing campaigns and campaign tracking.

## Where to start
- Entity/model: `Campaigns.php` (extends `data/CRMEntity.php`)
- Common UI actions:
  - `ListView.php`, `DetailView.php`, `EditView.php`, `Save.php`
  - AJAX entrypoints (`*Ajax*.php`)

## Related
- Leads/Contacts as campaign members
- Reports for campaign performance
