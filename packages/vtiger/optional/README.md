# `packages/vtiger/optional/` — optional vtiger add-ons (ZIP)

This folder contains optional ZIP packages such as:
- Language packs (e.g., French/Dutch/Deutsch/Spanish packs)
- Optional modules (e.g., Projects, Assets, RecycleBin, CustomerPortal, Webforms, etc.)

Notes:
- These ZIPs are installable through vtiger’s module management tooling.
- After installation, the active code is available under `modules/` and templates under `Smarty/templates/`.
