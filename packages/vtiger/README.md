# `packages/vtiger/` — packaged vtiger modules

This folder groups ZIP packages shipped with vtiger.

- `mandatory/` — core packages/features used by many installations
- `optional/` — add-ons (language packs, additional modules)

These ZIPs are typically imported/managed through vtiger’s admin UI (Module Manager) and vtlib tooling.

- `modules/Settings/ModuleManager/`
- `vtlib/Vtiger/Module.php`
