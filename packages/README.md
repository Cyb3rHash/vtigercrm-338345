# `packages/` — vtiger feature/module ZIP packages

This directory contains packaged vtiger modules/features as ZIP archives. These are commonly used by vtiger’s module manager/import mechanisms.

Structure:
- `packages/vtiger/mandatory/` — packages expected/required in many deployments
- `packages/vtiger/optional/` — optional add-ons (language packs, extra modules, utilities)

See also:
- `modules/Settings/ModuleManager/README.md` (module manager UI)
- `vtlib/README.md` (vtlib module lifecycle APIs)
