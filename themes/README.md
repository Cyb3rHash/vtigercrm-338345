# `themes/` — UI themes and assets

This directory contains vtiger themes (CSS/images) used by the server-rendered UI.

Common structure:
- `themes/<themeName>/` — theme-specific CSS and images
- `themes/images/` — shared images

Themes in this repo include:
- `alphagrey/`
- `bluelagoon/`
- `softed/`
- `woodspice/`

## Related
- Templating: `Smarty/` (see `Smarty/README.md`)
- Main UI entrypoint: `index.php`
- Common header/footer templates: often under `modules/Vtiger/` + Smarty templates
