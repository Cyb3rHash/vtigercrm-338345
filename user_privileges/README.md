# `user_privileges/` — generated permission/privilege artifacts

vtiger uses this directory to store **generated privilege files** used for fast permission checks at runtime.

Examples in this repo include:
- `default_module_view.php`
- `audit_trail.php`
- `enable_backup.php`

## How these files are produced
Privilege files are generated/re-generated by admin workflows, notably:
- `modules/Users/CreateUserPrivilegeFile.php`

## Notes for developers / operators
- In many deployments, additional files are generated here per-user (e.g., `user_privileges/user_privileges_<id>.php`).
- Treat most content here as **derived/generated**. Prefer updating configuration/roles/profiles via UI or the generating scripts rather than editing files manually.
